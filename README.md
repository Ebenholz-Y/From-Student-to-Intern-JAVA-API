# From-Student-to-Intern-JAVA-API

📖 前言（The Story）
大四在读，初入职场实习 1 周。

通常我们强调实习是学校到职场的衔接，但其实学校和实习之间也有一道巨大的鸿沟，尤其是技术类工作。本次实习我深有体验：

·我在学校使用的 Java IDE 还是 Eclipse，结课作业是写不到百行、包含继承和多态的迷你程序。

·而一看到实习中由成百上千个文件组成的企业级项目，我直接头晕眼花。

·即使想问 Mentor，也会因为“不知道问什么，从哪里问起”而更加迷茫。

我会在此仓库持续更新自己对 Java 后端 API 开发的学习与理解。虽然肯定比不上专业 Java 大佬的深度和广度，但这是一个“清澈的大学生”摸索着成为“没那么清澈的实习生”的真实记录。

平日里比较繁忙，可能缓慢更新。如果这些笔记对你有所帮助，欢迎点个 ⭐ Star 支持/追更，非常感谢！：）
